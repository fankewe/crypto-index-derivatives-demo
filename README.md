# crypto-index-derivatives-demo
Coding demo for crypto basket volatility and index derivatives...
This repository contains a small Python coding example for a presentation on crypto index products and derivatives.
The notebook constructs a simple five-token crypto basket using BTC, ETH, SOL, XRP and ADA daily prices from Yahoo Finance. It calculates log returns and compares the rolling 30-day annualized volatility of BTC, ETH and the crypto basket.
The purpose is to show that basket risk is not identical to single-token risk, supporting the case for index-level futures and options as cleaner hedging tools for crypto funds and ETFs.
